# Memory Collector: Learning Notes & Order of Operations

## Project Setup
- Folder: `Developer/github/Memory-Collector-Demo-Game`
- Language: Python 3

## The 5-Step Order of Operations
1. **Imports:** Bring in external tools (`import random`).
2. **State & Variables:** Create memory boxes before using them (`energy = 100`).
3. **Intro & Setup:** Welcome text and player name input (`input()`).
4. **Main Loop:** Interactive game loop running while `active == True`.
5. **Post-Loop:** Epilogue and outcome after the loop ends.

## Python Syntax Cheat Sheet
- `f"..."` -> Formatted string (lets us put `{variables}` directly in text).
- `\n` -> Adds a blank line (new line).
- `.append()` -> Adds a new item to the end of a List `[]`.
- `len(list)` -> Counts how many items are inside a list.
